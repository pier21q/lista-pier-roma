# Lista Pier Roma

Sito di Pier, PR a Roma: programma del weekend, stato dei locali e prenotazione di liste e tavoli su WhatsApp.

- `index.html`: la pagina.
- `programma.json`: serate del weekend, serate in arrivo e stato dei locali. Lo aggiorna ogni mercoledì sera la routine "Messaggio weekend PR · locali Roma".
- `media/`: foto e video delle serate.

Online su GitHub Pages: https://pier21q.github.io/lista-pier-roma/
